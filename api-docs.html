PDFMagic API Documentation

Integrate AI PDF summarization directly into your applications. Our REST API lets you summarize PDFs, chat with documents, and manage summaries — all programmatically.

Base URL

All API requests should be made to the following base URL:

https://api.pdfmagic.io/v1

All requests must be made over HTTPS. HTTP requests will be rejected. All responses are returned in JSON format.

Authentication

PDFMagic uses API keys for authentication. Include your API key in the Authorization header of every request.

🔑 Your API Key

API keys are available on the Business plan. Get yours from your Dashboard → Settings → API Keys.

Authorization: Bearer pm_live_xxxxxxxxxxxxxxxxxxxx
cURL
# Example authenticated request
curl https://api.pdfmagic.io/v1/account \
  -H "Authorization: Bearer pm_live_your_api_key_here" \
  -H "Content-Type: application/json"

Keep your API key secret. Never expose it in client-side code, public repositories, or logs. If compromised, regenerate it immediately from your Dashboard.

Quick Start

Summarize your first PDF in under 5 minutes. Here's a complete working example in JavaScript:

JavaScript
const fs = require('fs');

// Read PDF file and convert to base64
const pdfBuffer = fs.readFileSync('./document.pdf');
const pdfBase64 = pdfBuffer.toString('base64');

// Call PDFMagic API
const response = await fetch('https://api.pdfmagic.io/v1/summarize', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer pm_live_your_api_key',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    file: pdfBase64,
    type: 'brief',        // brief | detailed | bullets | academic
    language: 'English',  // output language
    save: true            // save to your account history
  })
});

const data = await response.json();
console.log(data.summary);  // Your AI summary!
console.log(data.word_count);
console.log(data.id);       // Summary ID for later retrieval

That's it! The API returns a JSON response with your summary, metadata, and a unique ID for the saved summary.

SDKs & Libraries

Official SDKs are available for popular languages. Community SDKs are also available on GitHub.

🟨
JavaScript / Node.js
npm install pdfmagic
🐍
Python
pip install pdfmagic
🐘
PHP
composer require pdfmagic/sdk
Python SDK
from pdfmagic import PDFMagic

client = PDFMagic(api_key="pm_live_your_api_key")

# Summarize from file path
result = client.summarize(
    file="./document.pdf",
    type="detailed",
    language="Hindi"
)

print(result.summary)
print(f"Words: {result.word_count}")

# Ask a question
answer = client.chat(
    summary_id=result.id,
    question="What are the key findings?"
)
print(answer.text)

Endpoints

POST /summarize Summarize a PDF document ⌄

Upload a PDF file (as base64) and receive an AI-generated summary. Supports 4 summary styles and 24+ output languages.

Request Body

ParameterTypeRequiredDescription
filestringrequiredBase64-encoded PDF file content
typestringoptionalbrief | detailed | bullets | academic (default: brief)
languagestringoptionalOutput language (default: English). See languages list.
savebooleanoptionalSave summary to account history (default: false)
webhook_urlstringoptionalURL to receive async webhook when processing completes

Response

● 200 OK
JSON
{
  "id": "sum_a1b2c3d4e5f6",
  "summary": "This research paper examines...",
  "type": "brief",
  "language": "English",
  "word_count": 142,
  "page_count": 32,
  "processing_time_ms": 4230,
  "created_at": "2026-05-26T10:30:00Z",
  "tokens_used": 1840
}
POST /chat Ask a question about a summarized document ⌄

Ask any question about a previously summarized document using its ID.

ParameterTypeRequiredDescription
summary_idstringrequiredID of the summary from /summarize
questionstringrequiredNatural language question about the document
languagestringoptionalResponse language (default: matches summary language)
GET /summaries List all saved summaries ⌄

Returns a paginated list of all summaries saved to your account.

ParameterTypeRequiredDescription
pageintegeroptionalPage number (default: 1)
limitintegeroptionalResults per page, max 100 (default: 20)
typestringoptionalFilter by summary type
DELETE /summaries/:id Delete a saved summary ⌄

Permanently delete a saved summary. This action cannot be undone.

GET /account Get account and usage information ⌄
Response JSON
{

Error Codes

PDFMagic uses standard HTTP status codes. All errors return a JSON body with a code and message field.

CodeStatusMeaning
invalid_api_key401API key is missing, invalid or expired
file_too_large400File exceeds 50MB limit for your plan
invalid_file_type400Only PDF files are supported
rate_limit_exceeded429Too many requests. See rate limits.
plan_limit_reached429Monthly API call limit reached. Upgrade plan.
processing_failed500AI processing error. Retry the request.

Rate Limits

Rate limits are applied per API key per minute. Exceeding limits returns a 429 error with a Retry-After header.
